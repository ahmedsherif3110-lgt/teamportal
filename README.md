# بوابة الفريق — النسخة المنظمة

هذه النسخة مبنية على مشروع `team-portal2027` الحالي، مع الحفاظ على هوية الألوان الزرقاء المستخدمة في صفحة العمليات القديمة، وإعادة تنظيم الصفحات والعمليات.

## ما تم تحديثه
- الصفحة الرئيسية مع مساحة واضحة لتوجيهات قائد الفريق.
- بيانات الموظف: الاسم، الكود الوظيفي، تاريخ التعيين، هاتف الطوارئ، أرصدة اعتيادي/عارضة/مرضي/بالخصم، وبدل المواصلات/الوجبات.
- صفحة العمليات وسجل العمليات، وكل عملية جديدة تبدأ بحالة `قيد المراجعة`.
- أنواع العمليات: طلب خاص، إجازة، إذن، صرف من الشئون الإدارية، وارد إلى الشئون الإدارية.
- الإجازات بدون حقل أسباب، والإذونات بدون حقل أسباب، مع حساب الأيام/الساعات من التواريخ والتوقيتات.
- قائد الفريق يملك `قبول وتنفيذ` أو `رفض`.
- الصرف الإداري لا يخفض المخزون عند الإرسال؛ يخفضه فقط عند القبول والتنفيذ.
- الوارد الإداري يزيد المخزون عند القبول والتنفيذ.
- تحذير نفاذ العنصر عند وصول الرصيد إلى صفر.
- إعدادات قائد الفريق تشمل قاعدة بيانات الموظفين والعمليات والشئون الإدارية والمخزون.
- المخزون مقسم إلى الأدوات المكتبية والأرشيف والعهدة.

## النشر على Firebase الحالي
لا تستخدم `firebase init` ولا تنشئ مشروعًا جديدًا.

```text
firebase.cmd use team-portal2027
firebase.cmd deploy --only hosting
```
